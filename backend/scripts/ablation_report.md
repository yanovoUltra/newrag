## 3. 结论

1. **rerank 是最大增益项**：生产完整（RRF+rerank）0.2180 显著高于无精排的三路 RRF 0.1881（+16%）。
   对数字型问答，精排把"同主题但错误年份/错误指标"的干扰块压下去，是召回质量的核心保障。
2. **BM25 基线对本语料几乎无贡献（0.0122）**：回答"是否应重做 BM25"——**不建议**。
   原因：① golden 全部是数字/指标型问题，词法（词频/IDF）对"1,707.48"这类数字串几乎无区分力；
   ② 模型原生稀疏（qwen3.7 稀疏输出）已承担词法召回职责（sparse-only 0.0715 > BM25 0.0122，高 5.9 倍）；
   ③ 中文 bigram 分词无词表建设成本，但收益远低于现有稀疏路。
3. **表格路价值被低估**：table-only 0.2008 > dense-only 0.1683。财报数字绝大多数落在表格块中，
   独立表格召回是对正文稠密召回的重要补充。
4. **稀疏路在无精排融合下会稀释结果**：dense+sparse（0.0901）< dense-only（0.1683）。
   原因：稀疏路 top 命中里大量"同词不同义"的无关块（如"营收"出现在多章节），RRF 融合把它们抬进 top8。
   **生产配置依赖 rerank 精排兜住这一稀释**——这解释了为何生产完整仍是最优。
5. **加权配比无法替代精排**：d0.7/s0.3 最优（0.1135），仍低于 dense-only；convex 加权仅改变两路比例，
   无法解决稀疏路自身的噪声问题，不值得改配比。
6. **golden 集局限**：8 题中"浦发基本每股收益"与"公司2023营业收入"全配置为 0——
   snippet 在语料中跨文档歧义/匹配失败（基本每股收益 1.28 在 600000 年报不同表格出现多次；
   "公司2023营收"86.5 亿同时命中 sample_report 与浦发年报中的相似数字）。绝对值偏低主因是评测集，
   但**配置间相对排序可信**。

## 4. 建议

- **保持当前生产配置**（三路 RRF + rerank，k=60）：实证最优，无需改动。
- **不重做 BM25**；如需强化词法，优先打磨模型原生稀疏的查询端权重而非引入第二套词法引擎。
- **后续可扩展**：① 扩充 golden 集（每文档多指标、含文本型问题），重新消融以消除评测集偏差；
  ② 按 chunk_type 分组评测（table 块 vs 正文块），验证表格元数据过滤检索的增益。

## 5. IDF × 结构块 方案对比（稀疏路治理）

- 日期：2026-08-10
- 脚本：`backend/scripts/eval_idf_structural.py`
- 评测集：现有 `eval_golden.json`（8 题）+ 新增财报 golden 10 题（茅台/比亚迪/宁德：营收 3 · 净利润 2 · 基本每股收益 3 · 加权平均净资产收益率 2），共 **18 题**，全部 rel 非空。
- 语料：Qdrant `chunks` 共 25573 点（已含文档侧 IDF 重写，生产状态）。
- 方法：结构块三模式（off / downgrade / exclude）× IDF{开,关}；IDF 关 = 查询稀疏除以 IDF（点乘还原原始得分，RRF 只用 rank，排序精确还原无文档 IDF 状态）。

### 5.3 结论

1. **结构块多模式已移除**：结构块占比仅 116/25573 ≈ 0.45%，off / downgrade / exclude 三模式实测完全一致、对召回零收益。据此移除 `STRUCTURAL_EXCLUDE` 与 off/exclude 分支，仅保留降权单一行为（`STRUCTURAL_CHUNK_ENABLED=true` 时结构块置后）。
2. **IDF 增益与问题类型强相关，扩集后全集是净负收益（NDCG@8 -0.0563）**：
   - 实体型（营收）：IDF 正收益（先前小集 NDCG@8 +4.6%、Rec@8 +7.4%）。
   - 标签型（净利润/净利率/ROE）：答点行靠"归属于上市公司股东的净利润"等**通用表头标签**识别，而 IDF 恰恰把这些高频标签降权，稀疏路找不到答点行 → 负收益（茅台净利 IDF 下 NDCG 0.000 vs noIDF 0.090；比亚迪净利 0.218 vs 0.613；茅台 ROE 0.000 vs 0.613）。
   - **同一 IDF 对两类问题方向相反**，是否保留取决于产品更侧重实体型还是标签型指标问答。
3. **指标级表格问答是检索层固有短板**：宁德 EPS / ROE 全配置 NDCG 0.000，稠密/稀疏/表格三路 top8 均未命中答点行，与 IDF 无关——建议对指标级问答转向**字段抽取**（结构化提取指标→独立索引）。
4. **golden 构造注意**：裸数值 snippet 会因子串误匹配（`_norm` 去逗号后 "300,065.66" 含 "65.66"、"11.12%" 命中百分比），EPS/ROE 须用「指标标签|数值」组合提高特异性，避免污染相关集。

### 5.4 建议

- IDF 是否保留：若产品侧重营收/实体型问答 → 保留；若侧重净利/ROE 等标签型指标 → **重跑 IDF 或按 query 类别动态开关**。当前为生产默认保留态。
- 结构块仅保留降权（多模式已移除）；如需彻底清理，可后续删除 `_apply_structural` 与 `is_structural` 标记。
- 指标级问答建议新增**字段抽取**管线（独立于检索层），而非继续依赖检索命中表格行。
