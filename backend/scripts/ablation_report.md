# 检索召回对比报告（消融网格 + BM25 基线）

## 5. IDF × 结构块 方案对比（稀疏路治理）

- 日期：2026-08-10
- 方法：结构块三模式（off / downgrade / exclude）× IDF{开,关}；IDF 关 = 查询稀疏除以 IDF（点乘还原原始得分，RRF 只用 rank，排序精确还原无文档 IDF 状态）。

### 5.1 结果总表（NDCG\@8 / Rec\@8）

| 配置                      | NDCG\@8    | Rec\@8     |
| ----------------------- | ---------- | ---------- |
| noIDF, struct=off       | **0.2444** | **0.1996** |
| noIDF, struct=downgrade | 0.2444     | 0.1996     |
| noIDF, struct=exclude   | 0.2444     | 0.1996     |
| IDF, struct=off         | 0.1881     | 0.1734     |
| IDF, struct=downgrade   | 0.1881     | 0.1734     |
| IDF, struct=exclude     | 0.1881     | 0.1734     |
| 生产默认（IDF + downgrade）   | 0.1881     | 0.1734     |

### 5.2 逐类问题（NDCG\@8，noIDF → IDF）

| 问题类型                | noIDF                 | IDF                   | 说明                 |
| ------------------- | --------------------- | --------------------- | ------------------ |
| 营收（实体型，公司名+年份主导）    | 0.160\~0.379          | 0.123\~0.379          | IDF 持平或略降，波动小      |
| 净利润（标签型，靠通用表头定位答点行） | 0.090 / 0.613         | **0.000 / 0.218**     | IDF 显著拖累           |
| 基本每股收益              | 0.613 / 0.613 / 0.000 | 0.613 / 0.613 / 0.000 | 仅宁德 0.000（检索不到答点行） |
| 加权平均净资产收益率          | 0.613 / 0.000         | **0.000 / 0.000**     | 茅台 IDF 下归零         |

### 5.3 结论

1. **结构块多模式已移除**：结构块占比仅 116/25573 ≈ 0.45%，off / downgrade / exclude 三模式实测完全一致、对召回零收益。据此移除 `STRUCTURAL_EXCLUDE` 与 off/exclude 分支，仅保留降权单一行为（`STRUCTURAL_CHUNK_ENABLED=true` 时结构块置后）。
2. **IDF 增益与问题类型强相关，扩集后全集是净负收益（NDCG\@8 -0.0563）**：
   - 实体型（营收）：IDF 正收益（先前小集 NDCG\@8 +4.6%、Rec\@8 +7.4%）。
   - 标签型（净利润/净利率/ROE）：答点行靠"归属于上市公司股东的净利润"等**通用表头标签**识别，而 IDF 恰恰把这些高频标签降权，稀疏路找不到答点行 → 负收益（茅台净利 IDF 下 NDCG 0.000 vs noIDF 0.090；比亚迪净利 0.218 vs 0.613；茅台 ROE 0.000 vs 0.613）。
   - **同一 IDF 对两类问题方向相反**，是否保留取决于产品更侧重实体型还是标签型指标问答。
3. **指标级表格问答是检索层固有短板**：宁德 EPS / ROE 全配置 NDCG 0.000，稠密/稀疏/表格三路 top8 均未命中答点行，与 IDF 无关——建议对指标级问答转向**字段抽取**（结构化提取指标→独立索引）。
4. **golden 构造注意**：裸数值 snippet 会因子串误匹配（`_norm` 去逗号后 "300,065.66" 含 "65.66"、"11.12%" 命中百分比），EPS/ROE 须用「指标标签|数值」组合提高特异性，避免污染相关集。

### 5.4 建议

- IDF 是否保留：若产品侧重营收/实体型问答 → 保留；若侧重净利/ROE 等标签型指标 → **重跑 IDF 或按 query 类别动态开关**。当前为生产默认保留态。
- 结构块仅保留降权（多模式已移除）；如需彻底清理，可后续删除 `_apply_structural` 与 `is_structural` 标记。
- 指标级问答建议新增**字段抽取**管线（独立于检索层），而非继续依赖检索命中表格行。

### 6.3 结论

1. **数字密集汇总表"显式召回"是最大增益来源**：锚点 + 字段回填共同把"主要会计数据/主要财务指标"表从 Top-15 外抬到 Top-1（中芯 2025 营收 67,323,192 千元实测）；Recall\@5 提高 5.3x 主要由表格路贡献。

### 11.2 Rec@8 口径核查（关键）

上一轮曾怀疑"v3 Rec@8=0.7218 与 NDCG 满分率 78.8% 矛盾（应为报告错误）"——**该推断有误，0.7218 是真实数据**。v5 逐题实证：

- **257 题中 179 题（70%）production 列 ranked 列表长度只有 1**（长度分布 {1:179, 8:78}），原因是**年份精确过滤 + 字段 relay 交互**：单一年份文档（如"中芯国际2025年年度报告.pdf"，全块 fiscal\_year=2025）中问 2024/2023 上年数据时，`fiscal_year=2024` 过滤把全部块滤掉（三路 0 命中），只剩字段索引回填的 relay 1 条。
- NDCG 满分率 83.7%（215/257）与 Rec\@8=0.7291 并存的数学原因：IDCG 取 `min(len(ranked), |rel|)`——列表仅 1 条时 IDCG=1.0，若该条相关则 NDCG=1.0，但 Rec\@8=1/|rel|（|rel| 个相关块只召回 1 个）。**NDCG\@8 满分 ⟹ Rec\@8=1.0 仅在 len(ranked)≥|rel| 时成立**，此前"下界 0.7877"的推断错在此。
- 一致性旁证：MRR=1.0（每题首条必中 relay）、Rec\@1=0.7022 **精确等于** mean(1/|rel|)=0.7022（每题只有 1 个相关块被召回时 Rec@1=1/|rel|）——数据自洽，无报告错误。
- **生产一致性**：answer.py 的年份回退（`year_fell_back`）仅在 blocks 为空时触发，而 metric 问题 relay 恒注入 1 条 → blocks 恒非空 → 上年问题生产环境同样只剩 1 条上下文，eval 与生产行为一致。

### 11.3 结论与优化建议

1. **Rec\@8=0.7291 偏低的主因是年份过滤语义，而非检索能力**：单年文档问上年数据时，正确答点块（含上年对比列）被 `fiscal_year` 精确过滤排除，检索层无块可召回，仅靠字段 relay 保底 1 条。rel>1 的上年题 Rec\@8 被压到 1/|rel|。
2. **优化方向（推荐，未实施）**：把年份回退触发条件从"blocks 为空"改为"年份过滤后无非 relay 结果即回退全量检索"（或年份语义改为 ≤ 文档年份）。预计多块相关集可完整召回，Rec\@8 显著提升，且 `year_fell_back` 元数据可如实标记。改动在 answer.py + eval\_ablation.py 同步，需回归"2023→true / 2024→false"旧测试。
